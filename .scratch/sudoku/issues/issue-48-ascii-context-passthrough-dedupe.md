## The duplication (ASCII-only, all in `src/renderer/ascii_renderer_alloc.zig`)

- `ProdFacadeContext` (lines 57–88): `deinit` + 4 pass-throughs (`render`, `showLegend`,
  `showError`, `getCommandInput`) delegating straight to `self.renderer.*`
- `MockFacadeContext` (lines 90–121): **byte-identical** 4 pass-throughs + `deinit`

The pass-throughs exist for exactly one reason: `facade.Make(Ctx).make(ctx_ptr)`
(ascii_renderer_alloc.zig:42) requires the context type to expose
`render`/`showLegend`/`showError`/`getCommandInput`/`deinit` so the comptime wrappers
generated by `Make` have methods to call.

Both contexts differ in exactly **one field**: the styler type (`*styler.AnsiStyler`
vs `*styler.PlainStyler`), which cascades into `AsciiRenderer(S)`. Everything else —
`allocator`, `writer`, `deinit`, and all 4 pass-throughs — is duplicated.

## What is / isn't shared across renderers

- **Shared:** only `facade.zig` — the `Facade` vtable struct (5 fn ptrs + `*anyopaque
  context`, facade lines ~17–49) and `Make(CT)` (facade.zig:52–89). That's the whole
  cross-renderer contract: a 5-method names contract.
- **Not shared:** `AsciiRendererAlloc`, `buildContext`, `prodBranch`/`mockBranch`,
  `ProdFacadeContext`, `MockFacadeContext`, `AsciiRenderer(S)`. A WASM or TUI renderer
  provides its **own** factory + context satisfying the same 5 names; it never imports
  this file. Consequence: refactoring or deleting the ASCII pass-throughs has **zero
  impact** on the shared seam as long as `Make` still gets a context exposing the 5 names.

## Candidate fix (ASCII-local, one file)

Define one generic context over the styler, and make the two existing contexts aliases:

```zig
fn ctx(S: type) type {
    return struct {
        allocator: std.mem.Allocator,
        writer: *std.Io.Writer,
        styler: *S,
        renderer: *ascii_renderer.AsciiRenderer(S),

        pub fn deinit(self: *@This()) void {
            self.renderer.deinit();
            const alloc = self.allocator;
            alloc.destroy(self.styler);
            alloc.destroy(self.renderer);
            alloc.destroy(self);
        }

        pub fn render(self: *@This(), view: board.Board.BoardView, status_msg: ?[]const u8) facade.Error!void {
            self.renderer.render(view, status_msg) catch return facade.Error.System;
        }
        // ... showLegend, showError, getCommandInput, identical to current bodies
    };
}

pub const ProdFacadeContext = ctx(styler.AnsiStyler);
pub const MockFacadeContext = ctx(styler.PlainStyler);
```

Deletes all 8 duplicated pass-throughs and both duplicate `deinit`s; `buildContext`,
`makeFacade`, `prodBranch`, `mockBranch` and `facade.zig` stay untouched.
